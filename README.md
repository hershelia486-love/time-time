# Time Tipping Compass

리치 노튼의 시간 장악 아이디어에서 출발해, **실천과 집중**에 초점을 둔 시간관리·다이어리 PWA입니다. 할 일을 **세 가지 색(오늘 꼭 하나 · 매일의 약속 · 틈틈이)**으로 좁히고, 감정을 관찰하고, 하루를 다이어리처럼 되돌아봅니다. 부드러운 파스텔 한지 톤의 디자인으로, 앱을 여는 것 자체가 부담스럽지 않게 만드는 것을 목표로 합니다.

## 화면 구성 (6탭)

- **오늘** — 지금 할 것만. 🔴 오늘 꼭 하나 · 🔵 매일의 약속(습관) · ⚫ 틈틈이(잡무) 세 블록 + 지금 기분 한 줄 + 보상 새싹
- **캘린더** — 월간·요일별 주간 보기, 날짜 이동, 필터, 여러 개 선택해 일괄 완료·삭제
- **루틴** — 매일의 습관 관리(요일 일괄 선택: 매일/평일/주말), 주간 점검
- **목표** — 오래 걸리는 큰 방향. "오늘 이 목표로 한 걸음"을 누르면 오늘의 빨강으로 연결
- **기록** — 🔖 북마크(웹·유튜브·스레드) · ✏️ 메모 · 🖼 사진
- **감정** — 하루를 흔든 감정을 관찰하는 저녁 성찰

## 주요 기능

- **3색 우선순위**: 색 하나로 무엇이 중요한지 결정 — 오늘 꼭 하나(빨강)에 집중, 잡무(검정)는 접어둠
- **감정 관찰**: 순간 기분 체크 + 하루 감정 흐름 + 저녁 감정 성찰 (판단하지 않고 관찰)
- **하루 다이어리**: 기분·습관·완료·생각을 남긴 시각을 자동으로 시간 타임라인에 기록
- **생각 정리함**: 떠오른 생각을 담아 🔴/⚫로 계획에 넣거나 버리기
- **연간 캘린더**: 12개월 색상 히트맵으로 "달마다·요일마다 무엇을 했나" 한눈에, 올해의 하이라이트
- **보상 새싹**: 빨강·파랑을 해내면 새싹이 자람 (줄지 않고 자라기만 — 죄책감 없음)
- **습관(루틴)**: 고정·비고정·월간·연간, 날짜별 계획·진행·완료·미룸 기록
- **목표 ↔ 오늘의 한 걸음** 연결, 진행률·마감일 현황
- **북마크·메모·사진** 기록 (사진은 IndexedDB 저장)
- **스와이프 삭제**, **여러 개 일괄 완료·삭제**, 길게 눌러 날짜·상태 이동
- **소프트 파스텔 한지 디자인**, 다크 없이 밝은 종이 질감
- `localStorage`(기록) + IndexedDB(사진) 저장, PWA 오프라인 캐시

## 로컬 실행

Node.js 18 이상이 설치된 환경에서 다음을 실행합니다.

```bash
node server.js
```

그 다음 브라우저에서 <http://localhost:4173>을 엽니다.

## 폰(Android)에서 설치하기

GitHub Pages 같은 HTTPS 주소에 배포한 뒤 Android Chrome에서 그 주소를 열고 **앱 설치** 또는 **홈 화면에 추가**를 선택하세요. 배포 후 주소는 보통 `https://<사용자>.github.io/time-time/` 형태입니다. 자세한 절차는 [README_실행_배포.md](README_실행_배포.md)를 참고하세요.

## 데이터 보관

기록은 사용하는 브라우저의 `localStorage`(사진은 IndexedDB)에만 저장됩니다. 코드 저장소에는 개인 기록이 업로드되지 않으며, 기기 간 자동 동기화는 되지 않습니다. 여러 기기에서 같은 데이터를 보려면 별도의 클라우드 저장(예: Supabase) 연동이 필요합니다.
