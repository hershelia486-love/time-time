# Time Tipping Compass

리치 노튼의 시간 장악 도구를 참고해 만든 **Android 우선 시간관리 PWA**입니다. 개인·경력·사람·여가의 네 영역과 오늘의 계획, 고정·비고정 루틴, 프로젝트, 성찰 기록을 한 화면에서 관리합니다.

## 주요 기능

- 오늘의 나침반: 일정·주간 루틴·프로젝트·도구·성찰 요약
- 월간·요일별 주간 캘린더, 가로·세로 보기, 날짜 이동
- 계획·진행·완료 상태와 금색 완료 표시
- 고정·비고정·월간·연간 루틴 및 날짜별 계획·진행·완료·미룸 기록
- 개인·경력·사람·여가 영역별 필터와 안내
- 프로젝트 마감일·진행률·연결된 할 일 현황
- 모바일 길게 누르기 기반 날짜·상태·우선순위 이동
- 모든 탭의 위로·아래로 빠른 이동 버튼
- `localStorage` 기반 개인 기록 저장 및 PWA 오프라인 캐시

## 로컬 실행

Node.js 18 이상이 설치된 환경에서 다음을 실행합니다.

```bash
node server.js
```

그 다음 브라우저에서 <http://localhost:4173>을 엽니다.

## Android에서 설치하기

GitHub Pages 같은 HTTPS 주소에 배포한 뒤 Android Chrome에서 해당 주소를 열고 **앱 설치** 또는 **홈 화면에 추가**를 선택하세요. 자세한 절차와 Android APK·위젯 준비 사항은 [README_실행_배포.md](README_실행_배포.md)를 참고하세요.

## 데이터 보관

이 버전의 기록은 사용하는 브라우저의 `localStorage`에만 저장됩니다. 코드 저장소에는 개인 기록이 업로드되지 않으며, 다른 기기와 자동 동기화되지 않습니다.
