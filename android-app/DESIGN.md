# Time Tipping Compass Android 위젯 설계

## 목표

기존 PWA를 Android 설치형 앱으로 열고, 홈 화면에서 **오늘의 루틴 완료 수와 다음 루틴**을 바로 확인할 수 있는 위젯을 제공한다. 앱에서 루틴 상태를 바꾸면 위젯도 같은 데이터로 갱신한다.

## 화면과 위젯

| 화면 또는 구성 | 내용 | 주요 동작 |
|---|---|---|
| 설치형 앱 | 기존 Time Tipping Compass PWA 전체 화면 | 할 일·루틴·프로젝트·성찰을 기존과 동일하게 관리 |
| 4×2 홈 화면 위젯 | 오늘 완료 수, 전체 루틴 수, 다음 루틴 제목, `앱 열기` 버튼 | 위젯을 누르면 오늘 화면으로 이동 |
| 2×2 홈 화면 위젯 | 완료 수와 다음 루틴 제목을 짧게 표시 | 위젯을 누르면 오늘 화면으로 이동 |

## 데이터 흐름

1. PWA는 Android 앱 내부 WebView에서 실행되고 기존 `localStorage`에 전체 데이터를 저장한다.
2. 기록을 저장할 때 JavaScript 브리지가 오늘의 루틴 요약만 Android `SharedPreferences`로 전달한다.
3. Android 위젯은 `SharedPreferences`의 요약을 읽어 표시한다.
4. 위젯을 누르면 앱이 열리고 PWA의 오늘 화면으로 이동한다.

이 구조는 개인 기록 전체를 외부 서버로 보내지 않는다. 위젯에는 당일 요약만 기기 내부에 저장된다.

## UX 원칙

모바일 위젯은 앱의 축약판이 아니라 **한눈에 보는 시작점**으로 유지한다. 따라서 스와이프·드래그 기능을 위젯에 넣지 않고, 오늘 완료 수와 다음 행동만 보여 준다. 상세한 체크·미루기·수정은 앱을 열어 처리한다.

## 빌드 방식

Android 프로젝트는 Gradle로 APK를 생성한다. GitHub Actions의 `Build Android APK` 워크플로가 `main` 브랜치에 위젯 프로젝트가 반영되면 디버그 APK를 빌드해 아티팩트로 보관한다. 설치 전에는 Android 설정에서 해당 브라우저 또는 파일 앱의 `알 수 없는 앱 설치`를 허용해야 할 수 있다.
